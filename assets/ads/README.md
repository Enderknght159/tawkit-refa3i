# مجلد الإعلانات

طريقتان لإضافة الإعلانات:

1. **من داخل الشاشة** — زر الإعدادات ← تبويب «الإعلانات» ← «أضف صور الإعلانات».
   تُحفظ الصور داخل متصفح جهاز العرض (IndexedDB)، ويمكن ترتيبها وحذفها من نفس اللوحة.

2. **من هذا المجلد** — انسخ صور الإعلانات هنا، ثم اكتب أسماءها في `manifest.json`:

```json
{
  "ads": [
    { "src": "assets/ads/lesson-1.jpg", "title": "درس التفسير" },
    { "src": "assets/ads/eid.jpg", "title": "صلاة العيد" }
  ]
}
```

تُعرض إعلانات المجلد بعد الإعلانات المضافة من الواجهة، ولا يمكن حذفها من اللوحة
(احذفها من الملف أو من المجلد).

الصور الثلاث `sample-*.jpg` المضمّنة الآن **نماذج للمعاينة** مأخوذة من مراجع هوية
الجامع؛ احذفها من `manifest.json` أو استبدلها بصورك.
